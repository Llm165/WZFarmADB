# WZFarmADB

WZFarmADB 是一个基于 ADB 的农场自动化工具，提供任务控制、状态检测与自动化操作。

> 当前项目处于测试开发阶段，功能和使用方式仍在持续完善。

## ✨ 主要功能

- 农场自动化操作
- 状态识别与异常处理
- 多任务流程控制
- ADB 设备连接与管理
- 后续提供图形化客户端
